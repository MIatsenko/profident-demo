# Profident — демо сайта (Нови-Сад)

Демо переделки действующего сайта стоматологии [profident.co.rs](https://www.profident.co.rs/).
Сделано как образец для первого письма: клиника работает с 1995 года, сайт — одностраничник
на шаблоне эпохи Bootstrap 3, услуги без отдельных страниц, записи онлайн нет.

## Что внутри
- `index.html` — одна страница, всё в одном файле, без внешних CDN.
- `assets/img/` — **только фотографии клиники** с их сайта (логотип, врачи, кабинеты, услуги).
  Ни одного стокового кадра: чужое заказчик узнаёт сразу.
- Тексты — в голосе клиники, факты только с их сайта: 1995 год, 7 врачей, 2 кабинета и
  операционный зал, 2000+ пациентов, адрес Войводжанска 38, телефон 021 63 63 847.

## Чего намеренно нет
- Цен: у клиники нет публичного прайса, выдумывать нельзя.
- Отзывов и наград: не проверяются.
- Служебных плашек «демо»: страница читается как настоящий сайт, `noindex` стоит в мета.

## Проверено
- 22 файла ассетов — все 200, битых нет.
- 1440×900: первый экран влезает (755 px), 4 колонки услуг, переполнения нет.
- 2560×1440: влезает (791 px), сетка держится.
- 390×844 (iPhone 13, WebKit): влезает (712 px), одна колонка, горизонтального скролла нет.
- Снимки телефона просмотрены глазами: шапка, герой, услуги, команда, контакты — без обрезки.
